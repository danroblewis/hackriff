Addressing the surface…

Drag pans both axes · Wheel zooms both, about the cursor · Shift + wheel zooms frequency only · Alt / Option + wheel zooms time only · Double-click the map sends the active pane there. Alt rather than Ctrl for time: macOS's own Ctrl+scroll zoom takes that event before the browser sees it, and Ctrl+wheel is also how a trackpad pinch arrives — so a pinch zooms both axes here, like any other plain wheel. A uniform zoom still moves two independent axes: each resolves its own pyramid level, stated per viewport below. Nothing on this page moves the radio.
