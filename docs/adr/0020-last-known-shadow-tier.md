# ADR-0020 — A fourth honesty tier: **last-known / stale** (the canvas's shadow), with grey's meaning unchanged

**Status:** PROVISIONAL. The *model* is the user's (2026-09-18, T-519, planning log B0.691; extended 2026-09-20 by T-527, which fills every gap in an observed column rather than only the ones after a sample) and is recorded, not proposed. What is proposed is where the value comes from and how it goes on the wire. A note, not a gate.

**Touches:** CLAUDE.md "The view" (the honesty tiers; grey = genuinely unobserved); ADR-0017 §1 and ADR-0019 (a signal's time extent — unchanged); `docs/16` §4; `docs/api.md` `GET /api/tiles` → `shadow`; `hk_store::Pyramid::last_known_search`, `hk_store::LastKnown::carry_forward`, `hk_store::ShadowFill`; `hk-api::tiles`; the client's `ui/src/surface/cellrule.ts` (T-520). Use case AWARE-011.

---

## Context

The canvas had three honesty tiers — **live-IQ detail**, **spectrum-history**, **survey overview** — plus grey for *genuinely unobserved*, and T-441's two further marks (*observed but not yet measured*, *unknown whether we looked*). A cell with no measurement **for the viewed (t, f)** rendered grey, even where the radio had swept that band a minute before and then left. The user wants that cell to show the band's **most-recent-known** spectrum, dimly: swept then departed = shadow; never swept = grey; re-swept = bright again.

The pyramid held recency (coverage's `Sampled.last`) and strongest-ever (`overview()`'s max-hold), but not the value last seen.

## Decision

1. **Last-known / stale is a tier of its own.** A shadow value is a real measurement **of an earlier time**, carried forward. It is never a measurement of the cell it is drawn on, so it must be unmistakable from any live tier (T-520 owns the look), and it always travels with **when** it was last true (`last_t_s`, absolute capture time) and **at what resolution** (the source level's cell, stated per run).
2. **Grey's meaning is unchanged.** Grey is still *nothing ever looked here that any retained record or measurement can show*, and it is still decided by the coverage plane alone. The shadow is drawn only where coverage says `unobserved`; a cell with no shadow value stays grey. `unknown` (T-423) and *observed-not-yet-measured* (T-441) keep their own marks. The shadow never replaces a measurement: a cell whose grid holds a value carries no shadow.
3. **Computed at query time, from the pyramid that exists.** No new maintained structure, and nothing on the capture thread (the T-453 constraint). `Pyramid::last_known_search` walks newest-first, fine-to-coarse through the ladder (seconds → minutes → quarter-hours → hours → days), each stage covering only the part of the past the finer one did not, so the whole retained horizon costs a few hundred rows per column; it stops when every column has a value or nothing older is held. Within a tile the value is then carried down the rows and replaced by the tile's own value wherever the tile measures one.
4. **The search never carries backward, and says what was not searched.** A coarse cell straddling the instant is used only where the tile's own grid proves its after-part empty; a window over budget, or whose coarse cell is not yet folded, is reported as *unsearched*, never as empty. Nothing is carried past the store's newest frame.
5. **Every time gap in a column that was ever observed is filled, and the one backward read is marked as such** (T-527, user 2026-09-20). A gap **after** any sample takes the nearest **past** sample; the stretch **before a column's first-ever sample** takes that first sample. A column with neither a sample nor an older value carries nothing. The two fills are **different claims** — *what it looked like when we last saw it* against *when we first saw it* — so they are different values on the wire (`fill` ∈ `{forward, backward}`), not a nuance of the timestamp, and each run reports the boundary **nearest** its own rows (a forward run its source cell's end, a backward run its start), so the age it implies is the smallest the evidence supports.

## Why the head of a column is the one place that may read backward (T-527)

Decision 4 and decision 5 look opposed and are not. The **search** refuses a value from after the instant it was asked about because that value would be evidence the caller does not have: it is being asked *what was known at `t`*, and a later measurement is not an answer to it. The **head fill** is a different question — *was anything ever observed in this column, and what did it look like* — asked about rows the tile's own grid proves nothing else covers. Carrying the first sample up is the least-inventive answer available: the alternative on the wire was grey, and grey says *nothing ever looked here*, which for an observed column is simply false. So the exception is confined to exactly the case where the true statement and the drawn one diverge, it comes from this tile's own grid rather than from a search, and it is labelled, so no reader can take it for a measurement of its rows or for a forward carry.

What it does **not** license: a backward fill never crosses a sample (it stops where the first one begins), never appears where anything older was found (that head is a forward carry), and never conjures a column — a column never observed still carries no run, which is what keeps grey meaning *we never looked*.

**Its case is real but not universal, and the numbers say so.** A head gap needs a column whose record *begins* inside the viewed window: a capture's start, or a retune onto new spectrum. Over an arriving band at the canvas's own tile unit that is half the tile — 32 768 cells at level 0, where before T-527 the whole zoom burst's finest five addresses carried *no runs at all*. Over a band tuned for the whole window it is zero, and the plane is unchanged.

## Consequences

- **The backward fill is free where the shadow was expensive.** It reads no source cell and changes no query — one push inside the row walk the carry already makes over the tile's own cells — and on T-461's coverage short-circuit, which hands the carry no grid, it cannot fire at all. Paired before/after over T-523's zoom-burst addresses: identical `source_cells` and `chunks` per level, search times inside run-to-run noise on both paths, and ~2 bytes per run for `fill`.
- **The shadow is only as deep as retention.** A band whose last measurement the byte budget has evicted at every level shows grey, although *coverage* records may still say it was looked at. That is honest about the value and conservative about the claim; a "looked, value no longer held" mark is a possible later refinement, not part of this decision.
- **Frequency resolution degrades with age**, because the ladder is welded: a value found at the day level is a 100 kHz cell replicated across finer columns (T-334's safe direction), and the wire says so.
- **Cost is bounded by the TILE's own scale, not the store's** (one lock hold per step, at most `cells × SHADOW_SEARCH_ROWS` source cells per search — T-523 cut it there after the original tile-read budget made T-461's coverage short-circuit, the route's cheapest answer, one of its most expensive). The budget is paid in the shadow's resolution, never in its reach. Over spectrum no tile holds, it answers from the tile index without reading a cell.
- Option (b) of the planning brief — a maintained per-frequency last-value structure — is deliberately not built; it is the fallback if query-time cost ever measures too high.
