## Fails on real hardware, passes on the mock

1. **Off-centre FM station not resolved as a channel.** With the pipeline tuned 0.70–0.80 MHz from a 22 dB station (still inside the 1.8 MHz filter), `/api/inventory` showed one 0.9–1.2 MHz wide row near the window edge instead of a ~200 kHz station. The run summary counted 6 emitters while the default `/api/inventory` list returned 1 row; this mismatch is unexplained. On the mock, SIGNAL-062 passes with the station 500 kHz from centre. The live serve HIL at 100.8 MHz (500 kHz offset) did list 101.3 MHz. Suspect the detection/clustering path at the baseband-filter skirt on live 8-bit IQ, or the test's window choice. Needs a follow-up run with the station nearer centre (the serve HIL shape) before blaming the pipeline.
2. **No RDS PI on live air.** 0 decodes in both acceptance runs and in the serve HIL, although WFM chains attached. On the mock fixture (recorded with this same HackRF and these gains) the PI decodes. Either this station's RDS is weak here, or live chains skip to the live edge and lose RDS groups.
3. **Survey sensitivity.** At 8 Msps the strongest station stood only ~22 dB above the channel floor, and only one station reached 20 dB, so a within-band retune window could not be chosen. Survey at 2.4 Msps (or with more averaging) next time.

## Harness changes (this commit)

- `tests/e2e/tests/acceptance/hil_hackrf.rs` (new): the live HIL test. Blind survey as truth held only by the test, then `hk serve --hackrf` blind, then detection/top-k, Listen, RDS PI, floor, occupancy, retune within band and drop accounting. Prints `HIL-RESULT` lines.
- `tests/e2e/tests/acceptance_m0.rs`: registers the module.
- `tests/e2e/tests/acceptance/listen.rs`: `open`, `first`, `close`, `band_power` and `db` made `pub` for reuse.
- `tests/e2e/tests/acceptance/device_variants.rs`: the stub `hil_blind_fm_survey_on_the_hackrf` (never opened the device) removed; doc comment points at `hil_hackrf.rs`.
- `tests/e2e/tests/acceptance/common.rs`: the `hardware_skip` message no longer says "not wired yet".
- One fix round between runs 1 and 2: survey floor quartile → 10th percentile, run-window edge 0.8 → 0.7 MHz, occupancy margin 0.5 → 0.25.
